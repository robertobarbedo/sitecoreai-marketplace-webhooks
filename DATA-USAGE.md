# Data usage disclosure

Webhooks is an app that runs inside SitecoreAI and manages both the
Authoring webhooks and the Experience Edge webhooks of an environment. The
Authoring tab works entirely in the browser through the Sitecore Marketplace
SDK, with the signed-in user's own permissions. The Experience Edge tab calls
the app's own server, which uses the stored Edge administration credentials
to call the Experience Edge Admin API. The app has no database and uses no
analytics; what it saves goes to the customer's own SitecoreAI environment.
Hosting: Vercel; serverless functions run in the United States (Vercel
default region `iad1`, Washington, D.C.) unless the deployment sets another
region.

See also the [Privacy policy](PRIVACY.md) and [Security policy](SECURITY.md).
